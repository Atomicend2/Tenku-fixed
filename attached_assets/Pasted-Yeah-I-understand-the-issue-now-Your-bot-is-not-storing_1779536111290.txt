MOST IMPORTANT PART

If you’re using newer Baileys versions, WhatsApp introduced LIDs.

So even m.sender may sometimes look weird.

You need to normalize the JID.

Use this:

import { jidDecode } from "@whiskeysockets/baileys"

function getRealNumber(jid) {
    if (!jid) return null

    if (/:\d+@/gi.test(jid)) {
        const decode = jidDecode(jid)
        return decode?.user || jid
    }

    return jid.split("@")[0]
}

Then:

const phone = getRealNumber(m.sender)
